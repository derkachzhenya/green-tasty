# Предзаказ владельца: реализация и проверка 29.10.2026

## Выполнено

- Общая подписанная ссылка приглашения без предварительного ввода имени владельцем. При переходе гость вводит имя и получает отдельный приватный предзаказ; повторный переход в той же сессии возвращает его к своему заказу. Проверяются вместимость, срок действия и отмена брони.
- Submit Pre-Order в корзине владельца отправляет групповой предзаказ ресторану. Повторная отправка не дублирует позиции. Старый API без send_to_restaurant сохраняет прежнюю семантику.
- Для отклонённой рестораном позиции запрещено увеличение количества; доступны удаление и существующий сценарий замены.
- Отзыв содержит две обязательные оценки звёздами: ресторан и обслуживание. Они сохраняются вместе с комментарием и восстанавливаются через Update Feedback.
- Приближены к предоставленным макетам карточки, размеры кнопок, групповой диалог, строки участников, статусы, предупреждения, итог и неактивная кнопка. Дополнительные сведения ресторана свёрнуты под списком участников.
- Добавлен и запущен локальный Docker scheduler. Логи подтверждают ежеминутное выполнение существующей команды pre-orders:expire для автоматического T−30 cut-off. Команда обрабатывает локальную рабочую БД по установленным правилам, сохраняя историю.

## Проверки

- Полный PHP suite: 577 passed, 28 skipped; 6483 assertions. Пропуски включают проверки, требующие MySQL/конкурентного выполнения.
- После последних изменений приглашения: 26 targeted tests passed, 321 assertions.
- UI suite: 32 файла, 288 tests passed. После финальных правок диалога дополнительно прошли 5 целевых тестов.
- TypeScript, production build, PHPStan (memory-limit=1G), форматирование новых PHP файлов и git diff --check прошли.
- В браузере на отдельном SQLite стенде localhost:18087 проверены общий invite link, ввод имени и приватное меню гостя, добавление блюда через Pre-Order, отправка владельцем смешанного заказа, удаление гостя, отклонённая позиция без увеличения количества, сохранение и повторное открытие двух оценок отзыва.

## Ограничения сверки

Это не подтверждение попиксельного совпадения всех 36 макетов. Для блюд без изображения сохранены буквенные заглушки. Новые приглашения после отправки группового заказа по-прежнему закрыты существующим правилом приложения. Финальная мобильная сверка не завершена: подключение Chrome зависло при изменении viewport; попытка сброса viewport также завершилась таймаутом.
